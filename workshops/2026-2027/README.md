# Εργαστήρια σχολικής χρονιάς 2026–2027

**Ένας αριθμημένος φάκελος ανά εργαστήριο.** Όλο το υλικό του εργαστηρίου συγκεντρώνεται εκεί, αντί να διασκορπίζεται στον κεντρικό φάκελο.

Παράδειγμα μελλοντικού εργαστηρίου:

```text
01-robot-model/
  index.html    (παρουσίαση)
  photos/       (φωτογραφίες κατασκευών)
  posters/      (αφίσες)
  files/        (PDF / φύλλα εργασίας)
```

Ο φάκελος `_TEMPLATE/` είναι έτοιμο καλούπι, **όχι δημοσιευμένο εργαστήριο**. Αντιγράφεται και μετονομάζεται όταν έχουμε το πρώτο πραγματικό εργαστήριο.
