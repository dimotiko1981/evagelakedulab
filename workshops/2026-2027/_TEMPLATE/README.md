# Καλούπι νέου εργαστηρίου

Αντίγραψε όλο το `_TEMPLATE` σε `01-...` και ενημέρωσε το `index.html`.

Πεδία ανά εργαστήριο: τίτλος, ημερομηνία, τμήμα (Α΄–Γ΄ / Δ΄–ΣΤ΄), στόχοι, κατασκευή, βήματα προγραμματισμού, πρόκληση, αποτελέσματα, βίντεο (προαιρετικός ασφαλής σύνδεσμος).

Τα αρχεία καταχωρίζονται μόνο στους φάκελους αυτού του εργαστηρίου:

- `photos/` — φωτογραφίες της κατασκευής, όχι αναγνωρίσιμων παιδιών χωρίς συγκατάθεση.
- `posters/` — αφίσα PDF/εικόνα.
- `files/` — οδηγίες, υλικό, φύλλα εργασίας PDF.
