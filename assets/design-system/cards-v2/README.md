# EVAGELAK EDU LAB — FINAL CARD MASTER PACKAGE v2

Πλήρες, αυτοτελές πακέτο για αποθήκευση στο δημόσιο GitHub repository `dimotiko1981/evagelakedulab`.

## Τι περιέχει
- `cards/`: **18 έτοιμα επεξεργάσιμα SVG** (3 LEVEL × 6 badges) με την εγκεκριμένη, σταθερή εξωτερική κάρτα, το ματ πλαίσιο και το **glossy navy εσωτερικό** (κυανές ακτίνες και λαμπερό δάπεδο).
- `masters/`: 3 αρχικά εγκεκριμένα ματ επίπεδα, χωρίς το badge.
- `badges/`: 18 αυτοτελή SVG μεταλλικών περιγραμμάτων, σε ματ Bronze/Silver/Gold, με διαφανές εσωτερικό.
- `source/`: τα πρωτότυπα εγκεκριμένα SVG, χωρίς μεταβολή.
- `references/`: οπτικές εικόνες αναφοράς, συμπεριλαμβανομένου του glossy εσωτερικού.
- `previews/`: προεπισκόπηση των 18 κενών ολοκληρωμένων καρτών.
- `manifest.json`: μηχανικά αναγνώσιμοι κανόνες και διαδρομές.

## ΚΛΕΙΔΩΜΕΝΑ ΧΡΩΜΑΤΑ
- `bronge` → LEVEL 1 → ματ Bronze `#A87850`.
- `silver` → LEVEL 2 → ματ Silver `#A8B0BB`.
- `gold` → LEVEL 3 → ματ Gold `#C5A04D`.

**Μόνο μέσα** στο περίγραμμα του badge: γυαλιστερό navy, κυανές ακτίνες, φωτεινότητα και γυαλιστερό δάπεδο. **Πάντα ματ εξωτερικό**, πλαίσιο, πινακίδες και badge.

## ΔΗΜΙΟΥΡΓΙΑ ΚΑΡΤΑΣ
Παράδειγμα: φωτογραφία και `gold badge 1 FRISBEE`.

1. Άνοιξε ΑΠΕΥΘΕΙΑΣ το αντίστοιχο αρχείο `cards/level-3-gold-badge-01-shield-MATTE-GLOSSY.svg`.
2. Στο SVG υπάρχει κενή, πραγματικά επεξεργάσιμη ομάδα `id="LEGO_PHOTO_CLIPPED_TO_BADGE"`. Πρόσθεσε σε αυτή την πραγματική φωτογραφία LEGO σε κατάλληλη κλίμακα· η ίδια ομάδα κάνει clipping στο εσωτερικό περίγραμμα.
3. Το αρχικό φυσικό μοντέλο πρέπει να παραμείνει ΑΚΡΙΒΩΣ ίδιο. Ούτε κατασκευή «από την αρχή» από AI, ούτε αντικατάσταση με ψεύτικα κομμάτια.
4. Αλλάζεις **μόνο** το κείμενο του `id="project-name-editable"` από PROJECT σε FRISBEE (ή άλλο). Η ένδειξη LEVEL και το ματ χρώμα είναι ήδη σωστά.
5. Εφόσον υπάρχει φωτογραφία με πραγματική αντανάκλαση, διατήρησέ την μέσα στο εσωτερικό. Το σταθερό glossy δάπεδο υποστηρίζει αλλά δεν δημιουργεί αυτόματα αληθινή αντανάκλαση συγκεκριμένου μοντέλου.
6. Τελική εξαγωγή: WebP, αναλογία 63:88, ζητούμενη διάσταση 5498 × 7680 px, συμπίεση όσο γίνεται ισχυρή χωρίς εμφανείς απώλειες. Ανάλυση 8K ≠ νέα πραγματική λεπτομέρεια.

**Σταθερό μέγεθος SVG**: 1260 × 1760 px· εκτυπωμένη κάρτα 63 × 88 mm. Δεν επιτρέπεται μετακίνηση του logo/LEVEL/nameplate/footer ή τροποποίηση της γεωμετρίας/των εξωτερικών χρωμάτων.

## ΣΗΜΑΝΤΙΚΕΣ ΔΙΕΥΚΡΙΝΙΣΕΙΣ
- Το glossy εσωτερικό του v2 είναι νέα διανυσματική υλοποίηση του εγκεκριμένου οπτικού κανόνα, και δεν είναι φωτογραφική αναπαραγωγή του αρχικού glossy παραδείγματος.
- Badge 2 και Badge 6: διανυσματικές ανακατασκευές εγκεκριμένων εικόνων (όχι εξαγωγές 1:1 των pixels).
- Ο φάκελος είναι **αρχείο προτύπων**, όχι αλλαγή σε υπάρχουσες HTML/JS/CSS σελίδες. Δεν αντικαθιστούμε υπάρχοντα αρχεία site.
- Τα SVG είναι δημόσια, εφόσον τα ανεβάσεις στο public GitHub repository.
- **Το ZIP δεν ανεβαίνει αυτούσιο**: αποσυμπίεση, άνοιγμα repository → `assets` → μεταφόρτωση του φακέλου `design-system/cards-v2` με την ίδια δομή.
- Μην ανεβάσεις αρχεία πάνω στο `cards-v1` εάν υπάρχει ήδη: ο φάκελος `cards-v2` είναι ξεχωριστός.


## v2.1 — ΜΟΝΙΜΟΣ ΚΑΝΟΝΑΣ ΔΙΑΦΑΝΩΝ ΕΞΩΤΕΡΙΚΩΝ ΓΩΝΙΩΝ

**Οι τέσσερις εξωτερικές στρογγυλεμένες γωνίες κάθε τελικής κάρτας είναι ΠΑΝΤΑ διαφανείς (RGBA alpha=0).** Αυτό ισχύει για τα 18 πρότυπα, ανεξαρτήτως LEVEL και badge. Η διαφάνεια διατηρείται τόσο σε 8K όσο και σε βελτιστοποιημένο WebP για site.

Τα SVG στο `cards/` και `masters/` διαθέτουν κλειδωμένη εξωτερική `clipPath` με αναγνωριστικό `CARD_ALPHA_BOUNDARY_DO_NOT_REMOVE`. Απαγορεύεται το flatten της τελικής εικόνας σε μαύρο/λευκό φόντο. Έλεγχος και των τεσσάρων corner pixels (alpha=0) μετά την εξαγωγή. Δες `TRANSPARENT_CORNERS_RULE.md`.

**Δομή μεταφόρτωσης:** Αποσυμπίεση ZIP και μεταφόρτωση με διατήρηση της διαδρομής `assets/design-system/cards-v2/`. Ο φάκελος `assets` υπάρχει ήδη στο site, συνεπώς πρέπει να **συγχωνευτεί**, ποτέ να αντικατασταθεί/διαγραφεί. Τα αρχεία που παλαιότερα είχαν ανέβει κατά λάθος στη ρίζα του repository δεν διορθώνονται αυτόματα από αυτό το ZIP.
