# EVAGELAK EDU LAB — εκπαιδευτική ρομποτική

Δημόσια ιστοσελίδα για τα εργαστήρια ρομποτικής της σχολικής χρονιάς 2026–2027. Δεν απαιτείται σύνδεση.

## Δομή (κανόνες)

- **`index.html`** — αρχική σελίδα. ΠΑΡΑΜΕΝΕΙ στο κεντρικό επίπεδο ώστε να λειτουργεί το GitHub Pages.
- **`assets/css/`** — εμφάνιση (CSS). Δεν βάζουμε εδώ αφίσες και φωτογραφίες εργαστηρίων.
- **`assets/js/`** — λειτουργία μενού, φίλτρων, κουίζ.
- **`assets/images/branding/`** — ΕΠΙΣΗΜΟ λογότυπο. Διατηρούμε το όνομα `evagelak-logo.png`.
- **`assets/images/illustrations/`** — εικονογραφήσεις που χρησιμοποιεί το site.
- **`workshops/2026-2027/`** — ένα υποφάκελο ανά νέο εργαστήριο (π.χ. `01-catapult/`).
- **`games/`** — μελλοντικές αυτόνομες εκπαιδευτικές δραστηριότητες.
- **`announcements/`** — νέα / πρόγραμμα / ανακοινώσεις.
- **`parents/`** — πληροφορίες και υλικό γονέων.

## Προσθέτω νέο εργαστήριο

1. Στον φάκελο `workshops/2026-2027/` αντιγράφω τον `_TEMPLATE/` ως `01-onoma-kataskevis/`, `02-onoma-kataskevis/` κ.ο.κ.
2. Βάζω φωτογραφίες στον **`photos/`**, αφίσες στον **`posters/`** και PDF στον **`files/`** του συγκεκριμένου εργαστηρίου.
3. Συμπληρώνω το `index.html` του εργαστηρίου και τους τίτλους. Δεν δημοσιεύω αναγνωρίσιμα παιδιά χωρίς κατάλληλη γονική συγκατάθεση.
4. Για να εμφανιστεί το εργαστήριο στην κεντρική λίστα της πρώτης έκδοσης, πρέπει να προστεθεί κάρτα στο `index.html` και η περιγραφή στον πίνακα `workshopDetails` του `assets/js/script.js`. Σε μελλοντική έκδοση αυτό μπορεί να αυτοματοποιηθεί με κατάλογο JSON.

**Κανόνας ονομασιών:** μικρά λατινικά, παύλες, χωρίς κενά, π.χ. `01-wind-turbine`. Για κάθε εργαστήριο, όλα τα δικά του αρχεία μένουν στον φάκελό του.

## Πώς δημοσιεύεται στο GitHub Pages

1. Repository `evagelakedulab` (Public).
2. Αποσυμπίεση του ZIP και ανέβασμα **των περιεχομένων του**, όχι του ZIP ούτε εξωτερικού φακέλου.
3. `Settings > Pages > Source: Deploy from a branch > main > /(root)`.
4. Διεύθυνση `https://USERNAME.github.io/evagelakedulab/` με το πραγματικό USERNAME.

## Αν αντικαθιστάς την προηγούμενη έκδοση

Ανέβασε πρώτα τα καινούρια `index.html`, `.nojekyll`, `assets/`, `workshops/`, `games/`, `announcements/`, `parents/` και το νέο `README.md`. Έπειτα, αφού ελέγξεις ότι όλα φορτώνουν, διέγραψε τα **παλιά** αρχεία στο root `styles.css` και `script.js`, και τα παλιά αρχεία μέσα στο root `assets/` (`official-logo.png`, `wind.svg`, `bin.svg`, `keeper.svg`, `shark.svg`, `hero-robot.svg`). Κράτησε τον νέο υποφάκελο `assets/images/`.

Η διαγραφή παλιών αρχείων ΔΕΝ γίνεται αυτόματα με ανέβασμα νέου ZIP. Πριν τη διαγραφή, έλεγξε αν υπάρχουν άλλες σελίδες που χρησιμοποιούν παλιές διαδρομές.
