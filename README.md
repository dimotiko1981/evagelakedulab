# EVAGELAK EDU LAB — αρχική σελίδα

Πρώτη λειτουργική έκδοση (2026–2027) της δημόσιας εκπαιδευτικής ιστοσελίδας ρομποτικής για παιδιά Δημοτικού και τους γονείς τους. Δεν απαιτείται σύνδεση.

## Αρχεία

- `index.html` — αρχική σελίδα στα ελληνικά.
- `styles.css` — σχεδίαση για υπολογιστή, tablet και κινητό.
- `script.js` — λειτουργικό μενού, φίλτρα εργαστηρίων, πληροφορίες μοντέλων, κουίζ τριών ερωτήσεων.
- `assets/*.svg` — ενδεικτικές, πρωτότυπες εικονογραφήσεις (όχι επίσημο λογότυπο).
- `.nojekyll` — ρύθμιση για GitHub Pages.

## Επίσημο λογότυπο

Περιλαμβάνεται η ίδια εικόνα που ανέβασε ο δημιουργός, προσαρμοσμένη μόνο σε μέγεθος (1100 × 1100 px) για ταχύτερη φόρτωση. Το λογότυπο βρίσκεται στο `assets/official-logo.png` και εμφανίζεται αυτόματα στην κεφαλίδα, στην αρχική ενότητα και στο υποσέλιδο. Δεν έχει ανασχεδιαστεί.

Η χρωματική παλέτα της δοκιμαστικής έκδοσης είναι προσωρινή.

## Δημοσίευση στο GitHub Pages

1. Δημιούργησε νέο **public** repository με όνομα `evagelakedulab`.
2. Αποσυμπίεσε το ZIP και ανέβασε **όλα τα περιεχόμενα** (τα `index.html`, `styles.css`, `script.js`, `README.md`, τον φάκελο `assets` και όπου είναι ορατό το `.nojekyll`) στη ρίζα του repository. Μην ανεβάσεις απλώς το ZIP σαν αρχείο.
3. Από `Settings → Pages` επίλεξε `Deploy from a branch` → `main` → `/(root)`.
4. Η δημόσια διεύθυνση θα είναι `https://USERNAME.github.io/evagelakedulab/`, όπου USERNAME το username στο GitHub.

## Τι είναι ενδεικτικό

- Οι τέσσερις κάρτες αναφέρονται σε παραδείγματα από προηγούμενα εργαστήρια, όχι σε επιβεβαιωμένο πρόγραμμα για το 2026–2027.
- Η ενημέρωση της σελίδας θα γίνεται προσθέτοντας υλικό από νέα εργαστήρια.
- Δεν υπάρχουν αναλυτικά προγράμματα ημερομηνιών, αιτήσεις συμμετοχής, πραγματικές φωτογραφίες παιδιών ή αποστολή προσωπικών δεδομένων.
- Οι εικόνες είναι εικονογραφήσεις, όχι φωτογραφίες των κατασκευών LEGO.
- Για φωτογραφίες/βίντεο αναγνωρίσιμων παιδιών απαιτείται προηγούμενη κατάλληλη συγκατάθεση και τήρηση των διαδικασιών του Συλλόγου.
